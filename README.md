Solmaris Heat — an original top-down open-world crime game in the browser. Rico Vale needs money, and Mira Sol has jobs: steal the marked Vela, run packages across Solmaris Bay, lose the heat, and finish the Sunset Run before the clock runs out. A procedural 3600×2600 city with 6 avenues, 5 streets, 7 named landmarks, live traffic, pedestrians, a wanted/police chase system with busted and wasted consequences, a cash economy, and a localStorage save. Zero dependencies, zero network, pure Canvas 2D + WebAudio synth.

Controls: WASD / arrows — move and drive · E — steal / enter a car, get out · Space — handbrake · P — pause · M — mute · Enter — start.

## Run it

```sh
node serve.ts --port 8080
# then open http://localhost:8080
# grader entrypoint:
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
